Problem
Star Shower needed consistent gameplay across desktop and mobile screens, with controls that let players collect stars and avoid hazards using their preferred input method.

Approach
I scaled gameplay to the canvas size, separated input and game behavior into JavaScript modules, and added keyboard, pointer, and touch controls. I chose colors and element sizes to accommodate accessibility needs and replaced a laggy multi-ribbon trail with a single optimized trail.

Outcome
The browser game supports desktop and mobile play through 10 levels, with multiple control options and keyboard-navigable menus. Shared scaling rules and modular code made it easier to refine gameplay across screen sizes.
